# 0002. X の認証を Cookie 方式だけにする

- ステータス: Accepted
- 日付: 2026-09-20 以前（v1.1.0）

## 背景（Context）

X は、自動操作ブラウザでのログインを制限している。ログイン画面で「続ける」を押しても反応しない。

## 決定内容（Decision）

ログイン操作は自動化せず、普段のブラウザのログイン済みセッションの Cookie（`auth_token` と `ct0`）を `.env` または `accounts.json` に設定し、それをヘッドレスのブラウザに渡す。ほかの認証方式は持たない。

## 理由と検討した代替案（Consequences / Alternatives）

- X の自動操作の制限を受けずに、ブックマーク画面を読み込める。
- Cookie はログイン情報そのものなので、Git 管理外のファイルにだけ置く。X からログアウトすると無効になり、取り直しが必要になる。
- 検討した代替案: 自動操作ブラウザでのログイン（v1.1.0 より前）。上記の制限のため使えなくなった。

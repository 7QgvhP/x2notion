# 0004. 重複判定の鍵をツイート ID にする

- ステータス: Accepted
- 日付: 2026-09-20 以前（v1.7.2）

## 背景（Context）

v1.7.1 までは、ツイートの URL 文字列で重複を判定していた。URL には @ハンドルが含まれ、ユーザーはいつでもハンドルを変えられるため、改名後に同じポストが二重登録された。

## 決定内容（Decision）

URL の `status/<数字>` からツイート ID を取り出し、`tweet:<ID>` を鍵にする。ID を取り出せない形式の URL だけは、`twitter.com` / `x.com` の表記ゆれとクエリ文字列を吸収した URL で比較する（`normalize_tweet_url`）。

## 理由と検討した代替案（Consequences / Alternatives）

- @ハンドルの改名による二重登録を防げる。
- 検討した代替案: URL 文字列（v1.7.1 まで）。上記の問題のため変更した。

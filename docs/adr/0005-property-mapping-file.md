# 0005. Notion のプロパティ名を対応表で管理する

- ステータス: Accepted
- 日付: 2026-09-20 以前（v1.5.0）

## 背景（Context）

Notion 側でプロパティの名前を変えたり削除したりすると、書き込みが失敗する。

## 決定内容（Decision）

ツール内部の項目と Notion のプロパティ名の対応を `properties.json` に持つ。値が `null` の項目は書き込まない。`properties --detect` で、現在のデータベースの構成から対応を推定して作り直せるようにする。実行前にプロパティの構成を検証し、合わなければ中断して対処を案内する（v1.2.0 で追加した検証）。

## 理由と検討した代替案（Consequences / Alternatives）

- Notion 側の改名・削除に、コードを変えずに追従できる。
- 重複判定ができない状態での二重登録を、実行前の検証で防ぐ。
- プロパティの型の変更には追従できない（Notion 側で戻す必要がある）。

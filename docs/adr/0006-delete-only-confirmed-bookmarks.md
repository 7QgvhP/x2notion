# 0006. X からの削除は、明示したとき、保存を確認できた分だけにする

- ステータス: Accepted
- 日付: 2026-09-20 以前（v1.6.0）

## 背景（Context）

X のブックマークを「未処理の受け皿」として使い、Notion へ移したら空にしていく運用をしたい。一方、X のブックマークからの削除は取り消せない。

## 決定内容（Decision）

- `--remove-from-x` を明示したときだけ削除する（既定では削除しない）。
- Notion への保存を確認できた分だけを削除する。
- 手動実行では件数を表示して確認を求め、自動実行では確認を省略する。
- `--dry-run` と併用すると、削除する件数だけを表示する。

## 理由と検討した代替案（Consequences / Alternatives）

- 取り消せない操作を、意図しないまま実行することを防ぐ。登録に失敗したポストが、どこにも残らなくなることを防ぐ。
- 削除したポストは、Notion で行を消しても再取得されなくなる。
